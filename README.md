# LittleOlive Restaurant Website

Responsive Restaurant Website

---

## Overview

**littleolive-restaurant-site** is a fully responsive restaurant website built using **HTML, CSS, and JavaScript**.

The project focuses on core frontend fundamentals, including semantic HTML structure, organized CSS architecture, responsive layout systems, and lightweight JavaScript interactions. It was built without frameworks to demonstrate a strong understanding of foundational web development concepts.

## 🛠 Tech Stack

| Technology               | Purpose                                    |
| ------------------------ | ------------------------------------------ |
| **HTML5**                | Semantic structure and page layout         |
| **CSS**                 | Styling, layout system, and responsiveness |
| **JavaScript**            | Navigation toggle and UI interactions      |
| **Ionicons**             | Icon library                               |
| **Google Fonts (Rubik)** | Typography                                 |

---  

## ✨ Features

→ Fully responsive restaurant landing experience

→ Structured hero section with primary call-to-action

→ “How It Works” section outlining the ordering process

→ Menu showcase with featured dishes and dietary categories

→ Testimonials section with customer reviews

→ Grid-based image gallery

→ Pricing and menu breakdown section

→ JavaScript-powered mobile navigation

→ Smooth scrolling navigation behavior

→ Structured call-to-action form

## Running Locally

Clone the repository:

```bash
git clone https://github.com/IbrahimQaar/littleolive-restaurant-site.git
cd littleolive-restaurant-site
```

Open `index.html` in your browser
or use Live Server in VS Code.

No installation or build tools are required.
